#### A Windows desktop beautification tool developed in C++. Simply specify the path to a video folder, and it will randomly loop the video footage on your desktop. Do not forcibly terminate the program through abnormal means, otherwise hidden desktop elements cannot be restored.
#### 基于C++开发的Windows背景美化工具，仅需指定视频文件夹路径，便会随机且循环的将视频画面呈现到您的桌面上；不要进行非常规方式强制终止该程序，否则将会导致隐藏的桌面元素无法恢复。
#### C++で開発されたWindows向けの背景美化ツールです。動画フォルダーのパスを指定するだけで、ランダムかつループ再生で動画の映像をデスクトップに映し出します。通常とは異なる方法で強制終了しないでください。隠されたデスクトップ要素が復元できなくなります。
#### C++로 개발된 Windows 배경 미화 도구입니다. 동영상 폴더 경로만 지정하면 무작위로 동영상을 반복 재생하여 바탕 화면에 보여줍니다. 비정상적인 방법으로 프로그램을 강제 종료하지 마십시오. 숨겨진 바탕 화면 요소가 복구되지 않습니다.
